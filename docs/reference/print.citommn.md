# Print a fitted MMN model

This function prints the architecture of a Multi-Modal Neural Network
(MMN) model created using the [`mmn`](mmn.md) function.

## Usage

``` r
# S3 method for class 'citommn'
print(x, ...)
```

## Arguments

- x:

  A model created by [`mmn`](mmn.md).

- ...:

  Additional arguments (currently not used).

## Value

The original model object `x`, returned invisibly.
